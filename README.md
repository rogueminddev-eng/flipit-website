# FlipIt

Convert documents, images and audio on your own Windows PC or Android phone. Conversion runs locally, with no account or file uploads.

**[Visit the website](https://rogueminddev-eng.github.io/flipit-website/)** · **[Download FlipIt](https://rogueminddev-eng.github.io/flipit-website/#availability)**

## What you can do

- Convert supported PDF, Word, Excel, CSV, text, JPG, PNG, MP3 and WAV files. See the [available conversions](https://rogueminddev-eng.github.io/flipit-website/#formats).
- Convert batches of the same file type on Windows.
- Scan pages on Android, adjust the four corners, and save as PDF, Word, JPG or PNG.
- Password-protect or unlock supported PDF, Word and Excel documents.

Android converts one file at a time. English text recognition can make mistakes; check important results against the original. Conversion between formats can change document layout.

## Download and install

| Device | Requirements | Installation |
| --- | --- | --- |
| Windows | Windows 10 or 11, 64-bit | Download `FlipItSetup.exe` from the website and run the installer. The installer is unsigned, so Windows may show a SmartScreen warning. |
| Android | Android 8.0 or later | Download `FlipIt.apk` from the website and open it. Android may ask you to allow installation from the app used to open the APK. |

Use the official download links above. SHA-256 checksums are available on the website and with each release to check the downloaded files.
