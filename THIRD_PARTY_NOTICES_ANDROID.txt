FlipIt for Android includes the third-party software listed below. Each
component stays under its own licence, and the full licence text for each is
available at the link beside it.

Nothing here is downloaded while you use FlipIt. Everything listed is inside
the app when you install it.


== The MP3 encoder, and what its licence asks of us

LAME 3.100
  Licence: LGPL-2.1-or-later
  https://lame.sourceforge.io/

LAME is built from its own sources, unmodified, and ships as its own shared
library - libmp3lame.so - with FlipIt's code in a separate one, libflipitlame.so,
that links to it when the app runs.

That arrangement is deliberate. LGPL-2.1 asks that you be able to replace LAME
with a different build of it without rebuilding the app around it, and keeping
the two apart is what makes that possible. The sources LAME was built from,
the library build files, and this notice are available with the public downloads:
https://github.com/rogueminddev-eng/flipit-website/releases
See the LAME source companion in the third-party materials asset. It contains
only the library sources and library build configuration.
