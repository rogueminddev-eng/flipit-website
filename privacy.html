Privacy

Your files stay on your device

FlipIt is built so there's nothing to collect. This page covers both apps — Windows and Android — and this website.

Both apps

  • Files never leave your device. Conversion runs in a temporary folder on your own PC or phone, which FlipIt deletes as soon as the file is done, or stopped.
  • No network connections. FlipIt has no code that talks to the internet — no uploads, update checks, crash reports, analytics or ads. Automated tests fail if networking code is ever added.
  • No account. There is nothing to sign up for, so FlipIt holds no name, email or payment details.
  • Passwords aren't stored. When you lock or unlock a file, the password goes straight to the converter and is forgotten once it finishes. It isn't written to disk, logged, or passed where other programs can read it.
  • Hidden metadata is removed by default. Converted files lose details such as camera model, GPS location, author and last-modified-by, unless you switch that off.
  • Your originals are only read. FlipIt writes new files and never changes or deletes the files you convert.

The Android app

  • It cannot reach the internet. The app asks for no internet permission at all, and its build removes that permission even if a library inside it asks for one. This is stronger than a promise: without the permission, Android itself refuses the connection.
  • No data is collected or shared. No accounts, no identifiers, no advertising, no analytics. Nothing about you or your files is sent anywhere, because there is nowhere for it to go.
  • It sees only the file you give it. FlipIt has no storage permission. You pick a file, or share one to it, and Android grants access to that one file. It cannot browse your phone.
  • Results stay in the app until you say otherwise. A converted file waits in FlipIt's own private folder. It is written where you choose only when you tap Save, and handed to another app only when you tap Share.
  • Text recognition runs on the phone. Reading a scanned page uses a language model built into the app. No page or image is uploaded for recognition.
  • Notifications only. The one permission FlipIt asks for is to show a notification, so a long conversion can report progress while you are in another app.

This website

  • The homepage counts one visit per open browser tab session through a small Cloudflare Worker API. It stores only the aggregate total and does not use cookies, read file names, or receive conversion activity.
  • Android and Windows download totals come from the download counts on public GitHub Releases. No app downloads are available until a release is published.
  • Fonts and images are served from this site. Cloudflare and GitHub may process basic network request information to provide their services.

Changes

If this ever changes, it will be announced in the release notes before the version that changes it.
